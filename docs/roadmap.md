# Built, and next

[← Back to overview](../README.md)

## Built

- Sign-in, roles and data scoping
- Reference data, with configurable instruments and performance levels
- Learners and enrolment, including roster import
- Assessment set-up with items per competency
- Grid encoder with live classification, and validated CSV/Excel import with a downloadable template
- Quality checks and the submit, verify, return and reopen workflow
- Automated classification and gap derivation
- Learner, class, school and division analytics: distributions, least-mastered competencies, trends, heatmaps, persistent gaps and technical-assistance flags
- Interventions with baseline, sessions, attendance, reassessment and effectiveness
- Individual Learning Monitoring Plans
- Ten report types in CSV, Excel and PDF
- Audit trail, retention, breach register and privacy notice
- A guided six-step move to the next school year

## Deliberately left for later

- Offline-first encoding with sync
- In-app and email notifications, and scheduled exports
- Item analysis (difficulty and discrimination)
- An early-warning module and integration with DepEd's learner information systems, which need official authorization
- Optional two-factor sign-in for administrators

## Before real-world use

The performance levels and competency lists in the demo are placeholders and are marked provisional. They need to be confirmed against current official issuances, and retention periods and alert thresholds agreed with the Data Protection Officer.
